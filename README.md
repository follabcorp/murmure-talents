# murmure-talents

Catalogue public des Talents de Murmure. Public catalogue of Murmure Talents.

Ce dépôt contient les Talents (`talents/`), la sélection (`featured.json`) et les révocations (`revoked.json`). Une CI les valide à chaque PR, puis publie l’index signé sur `https://talents.murmureai.tech/v1/`. Pour proposer un Talent, lire [CONTRIBUTING.md](CONTRIBUTING.md).

This repository holds the Talents (`talents/`), the featured list (`featured.json`) and the revocations (`revoked.json`). CI validates each PR, then publishes the signed index at `https://talents.murmureai.tech/v1/`. To propose a Talent, read [CONTRIBUTING.md](CONTRIBUTING.md).
