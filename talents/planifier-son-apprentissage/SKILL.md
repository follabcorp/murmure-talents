# Plan your learning

Produce a week-by-week plan from a goal and a deadline. Order the topics by prerequisites, and give more room to active practice and memory recall than to passive reading.

## Process

1. Turn a general intention into an observable result: specify what the person will be able to build, explain, or achieve. This result sets the scope.
2. Gather the deadline, the hours available each week, the starting level, and the preferred resource formats. If unknown, state the working assumption: a beginner with about five hours per week.
3. Break the subject down and order the notions: basics before applications. Group them into stages, each corresponding to a demonstrable skill.
4. Spread the time backward from the deadline, and reserve about **15% margin** for delays and reviews.
5. Plan each week: discovery through reading or video, **active practice** through exercises or a project, then **memory recall** through questions, flashcards, or self-assessment. Practice must dominate.
6. Space returns to older notions at increasing intervals, and alternate related subjects rather than isolating them in blocks.
7. End each stage with a concrete result or a self-test that checks mastery before moving on.
8. Present the plan: goal, assumptions, stages, then, for each week, the planned time, the target result, the resources by type, the exercises, the recalls, and the checkpoint. Propose a mix of book, course, documentation, and practice, without imposing a single source.
9. Add an adjustment rule: if behind, reduce the scope and keep the reviews; if ahead, go deeper or carry out a project.

## Adapting the path

| Situation | Choice |
| --- | --- |
| Exam on a fixed date | Start from the date; notions first, mock exams afterward |
| Skill without a deadline | Stages guided by projects, with notions learned as needed |
| Very little time | Strongly reduce the scope and use micro-sessions |
| Building regularity | Short daily slots rather than rare long sessions |
| Missing prerequisites | Add a foundations stage before the main path |

## Example adapted from the source

Goal: be comfortable with analytical SQL queries in six weeks, at five hours per week.

- Weeks 1–2: selection, filters, sorting, and basic functions. Check: answer twenty questions on a sample table.
- Weeks 3–4: joins, grouping, and subqueries. Result: a report of ten queries across three tables; also revisit the questions from the first weeks.
- Week 5: window functions and common expressions; rework three reports using subqueries.
- Week 6: complete analysis of a dataset and a self-assessment mixing the topics.

This is an example of a plan, with no program to be run by this Talent. Avoid chapter lists without exercises, timetables without margin, unverifiable goals, forgotten prerequisites, and reviews postponed to the eve of the exam.
